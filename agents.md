## Proyecto

El proyecto consiste en desarrollar una aplicación web de feedback, que será integrada a un sistema de solicitud de remolques, donde los usuarios pueden ofrecerse a remolcar otros autos o pedir ser remolcado. El funcionamiento del sistema es similar al de Uber, pero en un dominio diferente.

En la aplicación existen 3 tipos de usuarios:
- Towers: son quienes hacen de remolque
- Customers: son quienes necesitan ser remolcados
- Admins: son los administradores de la aplicación

Se le llama "trip" o "viaje" a cada servicio donde un remolcador remolcó un vehículo.


## Convenciones
- Nombres de variables y funciones en inglés
- Comentarios en español


## Tecnologías

El proyecto utiliza next.js con typescript estricto, tailwind CSS para el estilizado. Usamos clerk para la autenticación, supabase para la base de datos.
